## ✨ Features

- 🎞 **10 categories** — comedy, sci-fi, horror, action, thriller, mysticism, historical, drama, TV series and anime
- 📄 **30 title pages** with an embedded YouTube trailer, description and comments section
- 🖼 **Auto-playing slider** on the home page with swipe support on mobile
- 🍔 **Burger menu** for small screens
- 📱 **Responsive layout** — desktop, tablet and phone
- 🌌 Dark theme with hover animations on cards

## 🛠 Built with

- **HTML5** — semantic multi-page structure
- **CSS3** — Flexbox, media queries, transitions, `normalize.css`
- **Vanilla JavaScript** — slider (`setInterval`, touch events) and burger menu
- **Google Fonts** — Oswald, Roboto, Rubik

## 📁 Project structure

```
├── index.html              # Home page: slider + genre grid
└── Assets/
    ├── Pages/              # Genre pages and title pages (one folder per genre)
    │   └── Header/         # About and Contacts
    ├── Styles/             # Global styles, card styles, header pages
    ├── js/                 # slider.js, burger.js
    ├── Image/              # Posters and genre previews
    └── Logo/
```

## 🚀 Run locally

No build step — just open `index.html` in a browser.
